Saber fazer bons prompts é o que separa quem usa IA de forma básica de quem realmente tira proveito da tecnologia.

Aqui estão **20 prompts prontos** que você pode copiar e usar agora mesmo no ChatGPT, Gemini, Claude ou qualquer outra IA.

## Produtividade

### 1. Organizador de tarefas
```
Tenho as seguintes tarefas para fazer esta semana: [liste suas tarefas]. 
Organize em ordem de prioridade (urgente/importante) e sugira 
o melhor horário do dia para cada uma, considerando que trabalho 
das 9h às 18h.
```

### 2. Resumo de reunião
```
Vou colar as anotações de uma reunião. Organize em:
- Decisões tomadas
- Ações pendentes (quem faz o quê e prazo)
- Pontos em aberto
Anotações: [cole aqui]
```

### 3. Email profissional
```
Escreva um email profissional para [destinatário] sobre [assunto].
Tom: [formal/informal/amigável]. 
Objetivo: [o que você quer alcançar].
Mantenha curto (máximo 5 linhas no corpo).
```

## Estudos

### 4. Professor particular
```
Seja meu professor de [matéria]. Explique [tema] de forma progressiva:
1. Conceito básico (2 frases simples)
2. Como funciona na prática
3. Um exemplo real
4. Um exercício para eu resolver
Espere minha resposta antes de continuar.
```

### 5. Gerador de questões
```
Crie 10 questões de [matéria] no nível [básico/intermediário/avançado].
Formato: múltipla escolha com 4 alternativas.
Inclua gabarito comentado no final.
Estilo: [ENEM/concurso público/vestibular].
```

### 6. Mapa mental
```
Crie um mapa mental detalhado sobre [tema].
Use formato hierárquico com emojis:
📌 Tema principal
  ├── Subtema 1
  │   ├── Detalhe A
  │   └── Detalhe B
  └── Subtema 2
```

## Trabalho e Carreira

### 7. Currículo otimizado
```
Otimize meu currículo para a vaga de [cargo] na empresa [empresa].
Minha experiência: [descreva brevemente].
Destaque as palavras-chave que recrutadores buscam nessa área.
Formato: objetivo + experiência + habilidades (1 página).
```

### 8. Preparação para entrevista
```
Simule uma entrevista de emprego para a vaga de [cargo].
Faça 5 perguntas comuns, uma por vez.
Espere minha resposta e depois dê feedback construtivo 
sobre como melhorar cada resposta.
```

### 9. LinkedIn atraente
```
Reescreva meu resumo do LinkedIn para atrair recrutadores de [área].
Meu perfil atual: [cole ou descreva].
Use palavras-chave da área e mantenha tom profissional 
mas com personalidade. Máximo 3 parágrafos.
```

## Criatividade e Conteúdo

### 10. Ideias de conteúdo
```
Me dê 30 ideias de posts para [rede social] sobre o tema [tema].
Varie entre: educativo, entretenimento, pessoal e promocional.
Formato: [texto curto + ideia de visual/formato].
```

### 11. Roteiro de vídeo
```
Crie um roteiro para um vídeo de [X minutos] sobre [tema].
Estrutura: gancho (5s) + problema + solução + CTA.
Tom: [informal/profissional/divertido].
Público: [descreva].
```

### 12. Copy para vendas
```
Escreva uma copy de vendas para [produto/serviço].
Público-alvo: [descreva].
Dor principal: [problema que resolve].
Use a estrutura AIDA (Atenção, Interesse, Desejo, Ação).
Máximo 200 palavras.
```

## Programação

### 13. Debug de código
```
Analise este código e encontre os bugs:
[cole o código]
Para cada bug encontrado:
1. Explique o problema
2. Mostre a correção
3. Explique por que a correção funciona
```

### 14. Explicar código
```
Explique este código linha por linha como se eu fosse 
um iniciante em programação:
[cole o código]
Use analogias do dia a dia quando possível.
```

### 15. Gerar código
```
Crie um [tipo de programa] em [linguagem] que faça:
[descreva a funcionalidade]
Requisitos:
- [requisito 1]
- [requisito 2]
Inclua comentários explicativos no código.
```

## Análise e Decisão

### 16. Prós e contras
```
Analise os prós e contras de [decisão].
Meu contexto: [descreva sua situação].
Apresente em tabela e no final dê sua recomendação 
considerando meu contexto.
```

### 17. Pesquisa de mercado rápida
```
Faça uma análise rápida do mercado de [segmento] no Brasil em 2026.
Inclua: tamanho estimado, tendências, principais players, 
oportunidades para iniciantes e riscos.
```

## Saúde e Bem-estar

### 18. Plano alimentar
```
Sugira um cardápio semanal saudável e econômico.
Restrições: [alergias/preferências].
Orçamento: [valor] por semana.
Objetivo: [emagrecer/manter/ganhar massa].
Nota: consulte um nutricionista para orientação profissional.
```

### 19. Rotina de exercícios
```
Crie uma rotina de exercícios para fazer em casa, sem equipamentos.
Nível: [iniciante/intermediário/avançado].
Tempo disponível: [X minutos por dia].
Objetivo: [descreva].
Inclua aquecimento e alongamento.
```

## Finanças

### 20. Organizador financeiro
```
Me ajude a organizar minhas finanças. Minha renda é R$[valor].
Meus gastos fixos: [liste].
Use a regra 50-30-20 e sugira onde posso economizar.
Monte uma planilha simples com categorias.
```

## Dicas para Prompts Melhores

1. **Seja específico** — "escreva um email" é pior que "escreva um email de 3 linhas para meu chefe pedindo férias em tom respeitoso"
2. **Dê contexto** — quem é você, para quem é, qual o objetivo
3. **Defina formato** — tabela, lista, texto corrido, tópicos
4. **Defina tom** — formal, casual, técnico, divertido
5. **Peça revisão** — "revise e melhore" funciona como segundo passo

## Conclusão

Esses 20 prompts cobrem as situações mais comuns do dia a dia. Salve este artigo e use como referência sempre que precisar.

Lembre-se: o melhor prompt é aquele que você adapta ao **seu** contexto específico. Use esses como base e personalize.
